# 📊 Рубрика оценивания: Лабораторная работа 2.2 (Базовый RAG)

**Компетенции:** LLM-3 (3.1, 3.2, 3.3), PL-1 (1.1)  
**Максимальный балл:** 100 (переводится в оценку: 80-100=5, 60-79=4, 40-59=3, <40=2)

## Критерии оценивания отчета и реализации

| Критерий | Базовый уровень (3 / 60-79 баллов) | Продвинутый уровень (5 / 90-100 баллов) |
| :--- | :--- | :--- |
| **Чанкинг** | Реализован фиксированный размер с перекрытием (overlap). | Проведены эксперименты с разными стратегиями (sentence-based, recursive) с обоснованием выбора. |
| **Эмбеддинги** | Использована любая рабочая модель (OpenAI или HF). | Использована специализированная модель (напр., BGE-M3) с обоснованием её преимуществ для задачи. |
| **Векторная БД** | Использован FAISS (in-memory или сохранение на диск). | Использован Qdrant с настройкой фильтрации по метаданным (payload). |
| **Цитирование** | Модель указывает источники в ответе. | Источники корректно отформатированы (напр., `[1]`), есть проверка на галлюцинации (ответ "не знаю", если контекста нет). |
| **Метрика Recall@k** | Recall@5 ≥ 0.60 на тестовом наборе. | Recall@5 ≥ 0.75 на тестовом наборе. |
| **Качество отчета** | Отчет содержит все требуемые разделы и скриншоты. | Отчет содержит глубокий анализ компромиссов (latency vs качество) и выводы. |

## 🚩 Типичные ошибки студентов (Чек-лист для проверки)
- [ ] **Разрыв контекста:** Чанки слишком маленькие (<256 токенов) без перекрытия, из-за чего ответы "размазаны".
- [ ] **Отсутствие нормализации:** Векторы не нормализованы перед сохранением в FAISS (IndexFlatIP требует нормализации для косинусной близости).
- [ ] **Потеря метаданных:** В векторную БД сохраняются только векторы, без привязки к `source` или `chunk_index`, что делает цитирование невозможным.
- [ ] **Галлюцинации:** Промпт не содержит жесткого ограничения "Отвечай только по предоставленному контексту".
