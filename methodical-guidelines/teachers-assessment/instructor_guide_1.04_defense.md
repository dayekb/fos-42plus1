### Типичные ошибки студентов и как их предупреждать

| Ошибка | Описание | Как предупредить |
|---|---|---|
| Отсутствие версионирования | Промпты без версий, невозможно откатить | Требовать semver с самого начала |
| Монолитная структура | Все промпты в одном файле | Показать примеры модульной структуры |
| Нет обработки ошибок | Пайплайн падает при первой ошибке | Требовать try-catch и fallback |
| Отсутствие тестов | Код без автоматических тестов | Включить тесты в критерии оценки |
| Слабая документация | README без примеров использования | Давать шаблон документации |
| Игнорирование безопасности | Нет защиты от инъекций | Объяснять риски на лекциях |
| Отсутствие логирования | Невозможно отладить пайплайн | Требовать логирование всех этапов |
| Плохая презентация | Нечитаемые слайды, нет структуры | Проводить репетиции презентации |
