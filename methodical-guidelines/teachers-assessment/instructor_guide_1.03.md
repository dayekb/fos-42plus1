### Методические рекомендации преподавателю

**Перед занятием:**
1. Подготовить примеры медицинских документов (изображения).
2. Создать шаблоны JSON для валидации.
3. Подготовить тестовые наборы данных.
4. Проверить доступ к API (лимиты, ключи).

**Во время занятия:**
1. Первые 10 минут: разбор теоретического минимума.
2. 15 минут: демонстрация примера решения.
3. 45 минут: выполнение основного задания в парах.
4. 10 минут: разбор типичных ошибок.
5. 20 минут: презентация лучших решений.

**Типичные ошибки студентов:**
1. Отсутствие обработки ошибок.
2. Потеря контекста между этапами.
3. Слишком сложные промпты (лучше декомпозировать).
4. Игнорирование edge cases.
5. Отсутствие валидации выхода.
