### Методические указания

**Рекомендуемый стек:**
- Язык — Python 3.9+.
- Формат хранения — JSON / YAML.
- Тестирование — `pytest`, `promptfoo` (опционально).
- CI/CD — GitHub Actions / GitLab CI.
- Версионирование — Git + семантические теги.
- Шаблонизация — `string.Template` или `jinja2`.

**Организация работы в группе (до 4 человек):**
- **Team Lead** — координация, архитектура библиотеки.
- **Developer** — реализация загрузчика и CI/CD.
- **QA** — подготовка тестовых наборов и написание тестов.
- **DevOps** — настройка CI/CD пайплайна.

**Указания преподавателю:**
- Лабораторная работа рассчитана на 2 часа аудиторной работы + самостоятельное завершение в течение недели.
- В аудитории выделить время: 15–20 мин на проектирование, 20–25 мин на первый промпт, остальное — CI/CD и демонстрация.
- Предоставить шаблон YAML-файла и пример тестового набора.
- Для студентов, выполнивших работу на «отлично», предложить: A/B-тестирование, интеграцию с MLflow, анализ Logit Lens.
