# 📚 Методические ресурсы преподавателя

Этот раздел содержит справочные материалы, инструкции и методические указания, разработанные для поддержки преподавателей и ассистентов курса . 

Материалы помогают стандартизировать процесс обучения, ускорить проверку работ и оперативно решать типовые технические проблемы студентов.

---

## 🗂️ Содержание раздела

| Файл | Краткое описание |
| :--- | :--- |
| [`LLM_API.md`](./LLM_API.md) | **Работа с облачными API.** Руководство по интеграции LLM через REST API (на примере GigaChat). Включает схему авторизации OAuth 2.0, описание параметров запроса (`temperature`, `top_p`, `tools` и др.) и ссылки на документацию. |
| [`LLM_local.md`](./LLM_local.md) | **Локальный запуск моделей.** Инструкция по использованию Ollama: базовые CLI-команды, взаимодействие через локальный REST API (`localhost:11434`), ключевые параметры (`num_ctx`, `num_predict`) и объяснение принципов квантования (GGUF). |
| [`LLM_troubleshooting.md`](./LLM_troubleshooting.md) | **Решение технических проблем.** База знаний по частым ошибкам студентов: `Out of Memory` в Ollama, `401 Unauthorized` и `429 Too Many Requests` в API, проблемы с генерацией строгого JSON и "галлюцинации" RAG-систем. |
| [`LLM_cheatsheet.md`](./LLM_cheatsheet.md) | **Шпаргалка для семинаров.** Быстрые справочные таблицы: когда и как менять параметры генерации, уровни зрелости RAG-архитектур (Naive, Advanced, Agentic), расшифровка суффиксов квантования (`Q4_K_M`, `Q8_0` и др.) и контрольные вопросы для проверки самостоятельности выполнения работ. |
| [`lesson_1.02.md`](./lesson_1.02.md) | **Методические указания к занятию 1.02.** Описание рекомендуемого стека (Python, Jinja2, pytest, CI/CD), схема распределения ролей в учебной группе (Team Lead, Developer, QA, DevOps), поминутный тайминг аудиторной работы и дополнительные задачи для студентов, справившихся на «отлично». |

---

## 🎯 Как использовать эти материалы

1. **Подготовка к практическому занятию:**  
   Откройте [`LLM_cheatsheet.md`](./LLM_cheatsheet.md) и [`lesson_1.02.md`](./lesson_1.02.md) для быстрого освежения ключевых концепций, тайминга и ролевой модели работы в группах.
2. **Экспресс-помощь студентам:**  
   При возникновении ошибок у студентов сразу обращайтесь к [`LLM_troubleshooting.md`](./LLM_troubleshooting.md). Скопируйте готовое решение и отправьте его, чтобы не тратить время на повторную диагностику.
3. **Объективная оценка и защита:**  
   Используйте раздел *"Водяные знаки для проверки самостоятельности"* из [`LLM_cheatsheet.md`](./LLM_cheatsheet.md), чтобы задавать точные уточняющие вопросы во время код-ревью или защиты лабораторных работ.

## 🔄 Обновление материалов

Данный раздел является *living document* (живым документом). Если в ходе преподавания вы столкнулись с новой типовой ошибкой или нашли более эффективный способ объяснения темы:
1. Внесите изменения в соответствующий `.md` файл.
2. Сделайте коммит с понятным сообщением (например, `docs: добавить решение ошибки SSL в troubleshooting`).
3. Отправьте Pull Request в основную ветку репозитория.
