# Работа с API больших языковых моделей (на примере GigaChat)

> **Ключевые слова:** `API`, `LLM`, `REST API`, `GigaChat`, `OAuth 2.0`, `Access Token`, `Temperature`, `Top-P`, `Function Calling`, `AI-агенты`, `Stream`, `Prompt Engineering`.

## 1. Что такое API в контексте LLM?

**API (Application Programming Interface)** — это собирательное название набора команд и системных правил, которые образуют «язык-посредник», позволяющий различным программным продуктам корректно взаимодействовать друг с другом. 

В сфере больших языковых моделей (LLM) использование API позволяет:
- Настроить высокопроизводительный обмен данными между локальными и облачными сервисами.
- Легко интегрировать умный поиск, чат-ботов, машинный перевод и другие AI-функции в локальные продукты, даже на оборудовании со скромными вычислительными мощностями.
- Автоматически получать улучшения функционала вместе с обновлениями и выходом новых версий модели на стороне провайдера.

## 2. Доступность и требования курса

API существует для всех популярных больших языковых моделей, включая **GigaChat**, **ChatGPT-4**, **Claude 3**, **DeepSeek Coder** и другие. 

Работа через API существенно отличается от диалогового режима в веб-интерфейсе и требует:
1. Дополнительной авторизации.
2. В ряде случаев — оплаты используемых вычислительных ресурсов (параметры могут отличаться для физических и юридических лиц).

> ⚠️ **Требование курса:** Для изучения настоящего модуля достаточно авторизации в качестве **физического лица** с использованием полностью бесплатных тарифов (Freemium и аналогичных).

## 3. Практический пример: Схема доступа к GigaChat API

Доступ к GigaChat API осуществляется через REST-интерфейс на портале [Sber Developers](https://developers.sber.ru/). Процесс включает два основных этапа.

### Этап 1: Авторизация (OAuth 2.0)
Используется двухэтапная схема получения токенов:

1. **Authorization Key**  
   Базовый ключ доступа, генерируемый в личном кабинете проекта. Представляет собой строку в формате Base64: `Base64(Client_ID:Client_Secret)`.  
   *Передаётся в заголовке:* `Authorization: Basic <ключ>` при запросе временного токена.
2. **Scope**  
   Обязательный параметр, определяющий тип доступа. Для физических лиц используется значение: `GIGACHAT_API_PERS`.
3. **Access Token**  
   Временный токен, выдаваемый в обмен на Authorization Key.  
   - **Срок жизни:** 30 минут.  
   - **Использование:** Для всех последующих запросов передаётся в заголовке `Authorization: Bearer <access_token>`.  
   - *Примечание:* В официальных SDK обновление токена происходит автоматически.

### Этап 2: Отправка запроса к модели
Взаимодействие осуществляется посредством отправки **POST-запроса** на адрес:  
`https://api.giga.chat/v1/chat/completions`

## 4. Основные параметры запроса

Запрос может содержать явное указание значений параметров, существенно влияющих на результат генерации.

| Параметр | Описание и влияние на генерацию |
| :--- | :--- |
| `model` | Имя используемой модели (например, `GigaChat-Pro`, `GigaChat-Max`, `GigaChat-Lite`). |
| `messages` | Массив сообщений диалога. Поддерживаемые роли: `system` (задает стиль и правила), `user` (запрос), `assistant` (предыдущий ответ). |
| `temperature` | Управляет случайностью ответа. **Низкое значение:** детерминированный, предсказуемый текст. **Высокое значение:** непредсказуемая, творческая генерация с редкими метафорами (но с риском фактических ошибок и потери нити рассуждений). |
| `top_p` / `top_k` | Параметры ядра (nucleus/kernel sampling). Ограничивают выбор следующего слова только наиболее вероятными вариантами из распределения. |
| `max_tokens` | Максимальное количество токенов в ответе. Лимитирует длину генерации, предотвращая чрезмерную «болтливость» модели. |
| `stream` | Булевый флаг (`true` или `false`). При значении `true` сервер возвращает ответ по частям через Server-Sent Events (SSE), позволяя отображать текст в реальном времени по мере его генерации. |
| `frequency_penalty` | Штраф за повторяемость. Положительное значение уменьшает вероятность повторного использования одних и тех же слов и фраз. |
| `presence_penalty` | Штраф за присутствие. Поощряет модель говорить о новых темах, не упомянутых ранее в контексте. |
| `tools` / `functions` | Описание внешних функций в формате JSON Schema. Ключевой параметр для построения **AI-агентов**, способных вызывать внешние API (CRM, базы данных, калькуляторы). |

## 5. Актуальные версии и документация

- **Доступно в облачном API:** Линейка **GigaChat 2** (Lite, Pro, Max).
- **Ограниченный доступ:** Флагманская модель **GigaChat 3.5 Ultra** (выпущена в июле 2026 года) в настоящее время доступна только через веб-интерфейс, в качестве Telegram-бота и через мобильные приложения, но ещё не развернута в публичном облаке API.
