## 💡 Рекомендации по работе с материалами

1. **Начинайте с шаблонов.** Перед написанием кода откройте [Шаблон отчёта](./lab_report_template.md), чтобы понимать, какие артефакты (скриншоты, метрики, фрагменты кода) вам нужно будет собрать в процессе.
2. **Документируйте промпты сразу.** Используйте [Гайдлайн по документированию ИИ](./guidelines_gpt_documentation.md) с первого дня работы, чтобы не восстанавливать историю итераций по памяти.
3. **Следуйте таймлайну.** Не откладывайте настройку CI/CD и подготовку презентации на последний день. Используйте [Таймлайн подготовки](./defense_preparation_timeline.md) для планирования.
