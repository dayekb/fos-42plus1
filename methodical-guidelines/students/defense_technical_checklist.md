#### Чек-лист перед защитой

**Техническая готовность:**
1. Все компоненты работают локально.
2. Демо протестировано на разных данных.
3. Есть резервные скриншоты/видео.
4. Ноутбук заряжен, адаптеры есть.
5. Интернет стабилен (или есть offline-режим).

**Документация:**
1. README с описанием архитектуры.
2. Инструкция по запуску.
3. Примеры использования.
4. Описание тестов и метрик.

**Презентация:**
1. Слайды читаемы (шрифт ≥ 24pt).
2. Есть диаграммы и схемы.
3. Тайминг отработан (5–7 минут).
4. Репетиция проведена минимум 2 раза.

**Код:**
1. Код-стайл соответствует стандартам.
2. Нет закомментированных блоков.
3. Есть docstrings и комментарии.
4. Тесты проходят успешно.

**Ответы на вопросы:**
1. Подготовлены ответы на типовые вопросы.
2. Понимаю все компоненты своего кода.
3. Могу обосновать архитектурные решения.
4. Знаю слабые места и как их улучшить.
