# Модуль 4. Инженерия промышленного развертывания, мониторинга и оценки качества

**Дисциплина:** Инженерия систем на базе больших языковых моделей

## Ключевые компетенции модуля

| Код | Название |
| --- | --- |
| **PL-1 (PL-1.1)** | Разрабатывает и отлаживает прикладные решения с использованием Python |
| **LLM-1 (LLM-1.2)** | Выбирает и применяет метрики/подходы оценки производительности генеративных моделей |
| **LLM-5 (5.3)** | Настраивает API для работы с БЯМ |
