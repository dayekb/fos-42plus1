## 3. Итоговая формула расчёта

**Итог модуля** = 
`(балл_миникейс / 10) * 1.0` 
`+ (балл_тест1 / 10) * 1.0` 
`+ (балл_тест2 / 10) * 1.0` 
`+ (балл_расчет / 10) * 1.0` 
`+ (балл_практика / 100) * 1.5` 
`+ (балл_лаба / 100) * 1.5` 
`+ (балл_кейс / 100) * 1.0` 
`+ (балл_ср / 100) * 2.0` 
`+ (балл_защита / 100) * 10.0`

Итоговый результат округляется до одного знака после запятой.  
Максимальное значение — 20.0 баллов.
