# 📌 ЗАНЯТИЕ 4.1. Выбор модели и развертывание LLM-сервисов

## КИМ №1 (ОС №1). Мини-кейс: выбор модели

### Паспорт оценочного средства
| Параметр | Значение |
| --- | --- |
| Наименование ОС | Мини-кейс (выбор модели) |
| Вид КИМ | Мини-кейс |
| Компетенции | PL‑1 (PL‑1.1), LLM‑5 (5.3) |
| Уровень освоения | Базовый |
| Форма проведения | Практическое задание (индивидуально или в парах) |
| Трудоёмкость | 30 минут |

### Цель
Сформировать навык обоснованного выбора способа развёртывания БЯМ под ограничения по нагрузке, latency и бюджету.

### Сценарий
Ассистент службы поддержки: 5000 запросов/день, средняя длина входа 200 токенов, выхода 150 токенов, допустимая задержка p95 < 2 с, русский язык обязателен.

### Задание
Заполните сравнительную таблицу и сделайте обоснованный выбор между тремя вариантами:
1. Облачный API (OpenAI, GPT-4o-mini)
2. Локальный запуск (LLaMA-3-8B на Ollama)
3. Высокопроизводительный инференс (Mistral-7B на vLLM)

**Исходные данные для расчёта:**
- **Облако:** $0.15 / 1M входных токенов, $0.60 / 1M выходных; SLA p95 ≈ 0.8–1.5 с.
- **Ollama:** Аренда/амортизация эквивалентна $0.4/час при загрузке; среднее время ответа 1.5–3 с без батчинга.
- **vLLM на GPU:** Аренда $1.5/час; при батчинге p95 ≈ 0.5–1.2 с, утилизация 60–80%.
- *Месяц считать как 30 дней.*

### Ожидаемый результат
Заполненная сравнительная таблица по критериям (Стоимость/мес, Задержка p95, Качество 1–5, Сложность эксплуатации) + 5–8 предложений с обоснованием итоговой рекомендации.

### Критерии оценивания (20 баллов)
- Корректность расчётов стоимости и latency: 10 баллов
- Обоснованность выбора модели: 10 баллов
