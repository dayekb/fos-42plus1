### Цель
Проверить индикатор PL‑1.1: разработку и отладку прикладного решения на Python.

### Минимальные функциональные требования
1. `GET /health` → `{"status": "ok"}`
2. `POST /v1/chat` — тело: `{"messages": [{"role":"user","content":"..."}], "temperature": 0.2, "max_tokens": 256}`
3. Ответ: `{"reply": "...", "model": "...", "usage": {"prompt_tokens": N, "completion_tokens": M}, "latency_ms": N}`
4. Валидация входа через Pydantic (пустые сообщения — 422).
5. При ошибке LLM-бэкенда — HTTP 502/504 с понятным JSON `{"error": "...", "code": "..."}`.
6. Структурное логирование: `request_id`, `latency_ms`, `model`, `status`.
7. `Dockerfile`: сервис стартует командой `uvicorn app.main:app --host 0.0.0.0 --port 8000`.
8. Файл `.env.example` с переменными `MODEL_BASE_URL`, `MODEL_NAME`, `API_KEY`, `TIMEOUT_S`.
