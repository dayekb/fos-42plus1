### Цели и задачи
- Освоить автоматические метрики качества генерации: BLEU, ROUGE, METEOR.
- Научиться применять LLM-as-a-Judge и сопоставлять с Human Evaluation.
- Реализовать пайплайн оценки на Python (PL‑1.1) и интерпретировать результаты.

### Задания
1. Загрузить датасет (20–50 примеров пар «эталон – гипотеза» в CSV/JSONL) средствами Python.
2. Рассчитать BLEU и ROUGE-L для каждого примера и средние по датасету.
3. Вручную/полуавтоматически разметить 5 примеров экспертной оценкой 1–5.
4. Реализовать LLM-as-a-Judge (промпт + рубрика: фактичность, полнота, стиль) через API.
5. Сравнить ранжирование примеров по BLEU/ROUGE и по Judge; сделать вывод.
6. Оформить отчёт: таблицы, 2–3 кейса расхождения метрик, рекомендации по выбору метрик для продакшн-мониторинга.
