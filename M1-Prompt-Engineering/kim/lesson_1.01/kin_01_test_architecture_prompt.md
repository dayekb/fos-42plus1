# 📌 ЗАНЯТИЕ 1.1. Архитектура промпта и базовые паттерны

## КИМ №1. Тест с автопроверкой «Архитектура промпта и базовые паттерны»

### Паспорт оценочного средства

| Параметр | Значение |
| --- | --- |
| Наименование ОС | Тест по теме «Архитектура промпта и базовые паттерны» |
| Вид КИМ | Тест с автопроверкой |
| Компетенция | LLM-5. Промпт-инженерия |
| Индикаторы | 5.1, 5.2, 5.3 |
| Уровень освоения | Базовый (Б) |
| Форма контроля | Текущий контроль |
| Время выполнения | 20 минут |
| Количество заданий | 10 |
| Критерии оценки | 1 правильный ответ = 1 балл. 8–10 баллов — «зачтено», 0–7 — «не зачтено» |
| Тип заданий | Выбор одного правильного ответа, выбор нескольких ответов, установление соответствия |

---

### Тестовые задания

**1. Какой параметр API управляет степенью случайности (креативности) ответов модели?**

- A. top-p
- B. temperature
- C. max_tokens
- D. frequency_penalty

✅ **Правильный ответ: B**

---

**2. Установите соответствие между параметром генерации и его описанием:**

| Параметр | Описание |
| --- | --- |
| 1. temperature | A. Ограничивает выбор токенов первыми K наиболее вероятными |
| 2. top-p | B. Контролирует случайность; 0 — детерминированный вывод, выше — более креативный |
| 3. top-k | C. Ограничивает выбор токенов кумулятивной вероятностью p |
| 4. max_tokens | D. Ограничивает максимальную длину ответа |

✅ **Правильный ответ: 1-B, 2-C, 3-A, 4-D**

---

**3. Какой паттерн промптинга предполагает предоставление модели нескольких примеров выполнения задачи перед основным запросом?**

- A. Zero-shot
- B. Few-shot
- C. Chain-of-Thought
- D. Self-Consistency

✅ **Правильный ответ: B**

---

**4. Какие из следующих утверждений о Chain-of-Thought (CoT) промптинге верны? (Выберите все верные)**

- A. CoT требует, чтобы модель всегда выдавала ответ в одном токене
- B. CoT предлагает модели рассуждать пошагово, демонстрируя процесс решения
- C. CoT может использоваться как в zero-shot, так и в few-shot режимах
- D. CoT неэффективен для арифметических и логических задач

✅ **Правильные ответы: B, C**

---

**5. В чём заключается идея самосогласованности (Self-Consistency) при промптинге?**

- A. Модель всегда должна давать один и тот же ответ при любом промпте
- B. Генерируется несколько цепочек рассуждений через CoT, и финальный ответ выбирается большинством голосов
- C. Модель проверяет свой ответ на противоречия
- D. Промпт должен содержать только один пример

✅ **Правильный ответ: B**

---

**6. Какие элементы входят в архитектуру качественного промпта? (Выберите все верные)**

- A. Роль (system role)
- B. Инструкция / задача
- C. Количество параметров модели
- D. Контекст и ограничения
- E. Ожидаемый формат вывода

✅ **Правильные ответы: A, B, D, E**

---

**7. Для какой задачи лучше всего подходит zero-shot промптинг?**

- A. Для задач, требующих строгого соблюдения формата вывода
- B. Для простых, хорошо знакомых модели задач, где примеры не требуются
- C. Для задач, где нужно обучить модель новому поведению
- D. Только для задач классификации

✅ **Правильный ответ: B**

---

**8. Расположите этапы создания промпта в правильной последовательности:**

1. Определение роли модели
2. Формулировка задачи
3. Указание формата вывода
4. Добавление контекстной информации
5. (Опционально) Добавление примеров (few-shot)

✅ **Правильный ответ: 1 → 2 → 4 → 5 → 3** (или 1 → 2 → 4 → 3 → 5 — допустимый вариант)

---

**9. Какой параметр API ограничивает максимальное количество токенов в ответе модели?**

- A. temperature
- B. top_p
- C. max_tokens
- D. presence_penalty

✅ **Правильный ответ: C**

---

**10. Прочитайте промпт и определите, какие техники в нём используются:**

> «Ты — эксперт по анализу медицинских документов. Проанализируй следующее заключение врача и извлеки из него: (1) диагноз, (2) назначенные препараты, (3) дату следующего приёма. Вот пример правильного извлечения для другого документа: [пример]. Теперь выполни ту же задачу для: [текст документа]»

Какие техники промптинга применены? (Выберите все верные)

- A. Определение роли (role prompting)
- B. Few-shot
- C. Chain-of-Thought
- D. Структурированный формат вывода

✅ **Правильные ответы: A, B, D**
