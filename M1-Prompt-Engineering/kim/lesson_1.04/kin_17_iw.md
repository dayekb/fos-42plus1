### Постановка задачи

Разработать библиотеку промптов для мультимодальной обработки медицинских документов в мобильном приложении. Библиотека должна включать:

1. **Промпт для классификации документа** — определяет тип документа (заключение, рецепт, анализы, направление, план лечения) и его качество
2. **Промпт для извлечения сущностей** — выделяет ФИО, даты, диагнозы, препараты, дозировки, врача, клинику
3. **Промпт для маскировки ПДн** — заменяет персональные данные на маскированные значения
4. **Промпт для оценки уверенности** — оценивает качество распознавания и формирует рекомендацию
5. **Промпт для суммаризации** — создаёт краткое резюме документа для врача

---

### Требования к библиотеке

1. Каждый промпт должен иметь версию, описание, примеры использования
2. Должна быть документация по каждому промпту
3. Промпты должны быть протестированы на 5+ примерах
4. Реализована система версионирования (v1, v2, ...)
