---

### Постановка задачи

Реализовать условный пайплайн, который обрабатывает расписания из разных медицинских сервисов. Пайплайн должен:

1. Определять формат входных данных (JSON, XML, CSV, HTML)
2. Выбирать соответствующий промпт для парсинга
3. Извлекать обязательные поля (дата, время, врач, статус слота)
4. Валидировать данные и обрабатывать ошибки
5. Формировать единый формат на выходе

---

### Условия выполнения

1. Предусмотреть обработку 3+ различных форматов
2. Реализовать fallback-промпт для неизвестных форматов
3. Обеспечить логирование всех этапов пайплайна
4. Написать минимум 3 теста для проверки работы пайплайна
