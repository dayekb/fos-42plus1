### Постановка задачи

Настроить CI/CD-пайплайн для автоматического тестирования и развёртывания библиотеки промптов. Пайплайн должен включать:

#### Автоматические проверки

1. Валидация синтаксиса промптов
2. Тестирование на тестовых кейсах (не менее 10)
3. Проверка соответствия шаблонам

#### Канареечное развёртывание

1. Развёртывание новой версии на canary-окружение
2. Автоматическое сравнение метрик качества (с A/B-тестированием)
3. Откат при падении метрик

#### Документация

1. Автоматическая генерация документации из метаданных
2. Обновление README и примеров использования
