### Цель занятия

Формирование у обучающихся компетенций по проектированию, реализации и защите production-ready решений на базе БЯМ: структурированных библиотек промптов с версионированием, сложных условных пайплайнов с обработкой ошибок и fallback-сценариями, а также навыков презентации и обоснования архитектурных решений перед экспертной комиссией.

#### 2. Feature Flags для управления поведением агента

```python
feature_flags = {
    "enable_multimodal": True,
    "use_cot_reasoning": True,
    "strict_validation": False,
    "fallback_model": "gpt-3.5-turbo",
    "max_retries": 3,
    "timeout_seconds": 30
}

# Динамическое переключение без перезапуска
if feature_flags["enable_multimodal"]:
    result = multimodal_pipeline.process(image)
else:
    result = text_only_pipeline.process(text)
```

#### 3. Паттерны обработки ошибок

1. **Retry with backoff** — повторные попытки с экспоненциальной задержкой.
2. **Fallback** — переход на упрощённую модель/промпт.
3. **Circuit breaker** — временное отключение при множественных ошибках.
4. **Graceful degradation** — частичная деградация функциональности.
5. **Manual review** — передача на ручную проверку при низкой уверенности.

#### 4. Защита от промпт-инъекций

1. Разделение системных и пользовательских инструкций.
2. Экранирование специальных символов.
3. Валидация входных данных (regex, schema).
4. Ограничение длины входных данных.
5. Использование sandbox-окружения.
6. Мониторинг аномалий в выводах.

#### 5. Метрики качества промптов

1. **Точность (accuracy)** — доля корректных ответов.
2. **Полнота (recall)** — доля извлечённых сущностей.
3. **F1-score** — гармоническое среднее точности и полноты.
4. **Latency** — время отклика.
5. **Token usage** — расход токенов.
6. **Cost** — стоимость вызова.
7. **Hallucination rate** — частота галлюцинаций.
8. **Consistency** — стабильность ответов.
