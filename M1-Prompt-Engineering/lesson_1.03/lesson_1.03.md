## Занятие 1.3. Сложные сценарии и мультимодальность

### Общие сведения

| Параметр | Значение |
|---|---|
| Тема | Сложные сценарии и мультимодальность |
| Форма проведения | Практическое |
| Продолжительность | 2 часа |
| Компетенция | LLM-5 |
| Индикаторы | 5.4 (дизайн и структура промптов), 5.7 (мультимодальные промпты) |
| Уровень | Средний |

### Цели занятия

Сформировать компетенции по проектированию сложных многоступенчатых промптов с использованием:
- условной логики,
- цепочек рассуждений (`Chain-of-Thought`),
- мультимодальных подходов для обработки разнородных данных.

### Задачи занятия

**Знать:**
- Принципы построения условных промптов и ветвления логики.
- Методы организации цепочек промптов (`prompt chaining`).
- Особенности мультимодальных промптов (текст, изображение, аудио).
- Техники обработки ошибок и валидации результатов.

**Уметь:**
- Проектировать многоэтапные пайплайны обработки данных.
- Реализовывать условную логику в промптах.
- Комбинировать различные модальности в едином сценарии.
- Оценивать уверенность модели и принимать решения о ручной проверке.

**Владеть:**
- Навыками декомпозиции сложных задач на этапы.
- Техниками передачи контекста между этапами цепочки.
- Методами отладки и оптимизации многоступенчатых промптов.

### Теоретический минимум

#### 1. Условные промпты

```
Если [условие], то [действие 1], иначе [действие 2]
```

**Пример:**
```
Если документ является рецептом, извлеки названия препаратов и дозировки. 
Если это заключение врача, извлеки диагнозы и рекомендации.
```

#### 2. Цепи промптов (Prompt Chaining)

```
Этап 1 → Этап 2 → Этап 3 → Результат
```

**Пример:** Классификация → Извлечение текста → Извлечение сущностей → Валидация.

#### 3. Мультимодальные промпты

- **Image-to-Text:** Анализ изображений, OCR, описание сцен.
- **Text-to-Image:** Генерация изображений по описанию.
- **Audio-to-Text:** Распознавание речи, анализ тональности.
- **Multimodal Fusion:** Комбинация нескольких модальностей.
