### Тестовые задания

**1. Что такое Prompt Registry (реестр промптов)?**

- A. База данных для хранения истории чатов с LLM
- B. Централизованное хранилище для управления версиями и жизненным циклом промптов
- C. Инструмент для визуализации архитектуры нейронных сетей
- D. Сервис для мониторинга использования API

✅ **Правильный ответ: B**

---

**2. Какие практики относятся к версионированию промптов? (Выберите все верные)**

- A. Использование семантического версионирования (SemVer) для промптов
- B. Хранение только финальной версии промпта
- C. Отслеживание изменений через Git-подобные диффы
- D. Возможность отката к любой предыдущей версии
- E. Использование release labels (prod, staging, beta)

✅ **Правильные ответы: A, C, D, E**

---

**3. Какой подход рекомендуется для организации промптов по окружениям?**

- A. Хранить все версии в одной папке без маркировки
- B. Использовать release labels для указания стадии (prod / staging / beta)
- C. Создавать отдельный репозиторий для каждого окружения
- D. Использовать разные модели для разных окружений

✅ **Правильный ответ: B**

---

**4. Установите соответствие между этапом CI/CD и действием с промптами:**

| Этап CI/CD | Действие |
| --- | --- |
| 1. Pull Request | A. Запуск регрессионных тестов промптов |
| 2. Сборка | B. Инкрементальное тестирование только изменённых промптов |
| 3. Деплой в staging | C. Проверка качества и A/B-тестирование |
| 4. Продакшен | D. Мониторинг и сбор метрик производительности |

✅ **Правильный ответ: 1-A, 2-B, 3-C, 4-D**

**5. Что позволяет делать техника Logit Lens при отладке промптов?**

- A. Увеличивать скорость генерации ответов

- C. Автоматически исправлять ошибки в промптах
- D. Сжимать промпты для экономии токенов

✅ **Правильный ответ: B**

**6. Какие инструменты используются для механистической интерпретации LLM? (Выберите все верные)**

- A. Выравнивание текста по левому краю
- B. Настройка модели для следования инструкциям и снижения галлюцинаций

- C. Фильтрация обучающих данных

- E. Детекция галлюцинаций на основе скрытых состояний

**9. Почему промпты рекомендуется хранить отдельно от кода приложения?**

- D. Это улучшает производительность модели
