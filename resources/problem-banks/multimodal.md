# Банк задач «Мультимодальная обработка»

**Аннотация:** Задачи с изображениями (сканы документов, фото низкого качества, артефакты) на классификацию документа, извлечение текста, оценку уверенности. Упражнения на настройку OCR и обработку визуальных искажений.

---

## Задача №1. Обработка низкого качества изображения

**Условие:**  
Разработайте мультимодальный промпт для извлечения текста из изображения медицинского документа. Если качество изображения низкое (размытие, тени, наклон), промпт должен зафиксировать это и установить `confidence_score` < 0.6 и `requires_manual_review = true`.

**Проверяемый результат:**  
- Распознан текст (OCR)  
- Выставлена адекватная оценка уверенности  
- При низком качестве — флаг на ручную проверку  
- Отсутствуют галлюцинации  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
Изображение (скан рецепта с тенью и наклоном 15°).  

**Эталон / подход к проверке:**  
Извлечённый текст сравнивается с эталоном (если он известен). Проверяется: `confidence_score < 0.6`, `requires_manual_review = true`. Текст не должен содержать выдуманных данных.

**Варианты параметризации:**  
- Изменить степень зашумления (блики, смазывание)  
- Добавить таблицу на изображении  
- Изменить тип документа (заключение, анализы)

---

## Задача №2. Классификация типа документа

**Условие:**  
Напишите мультимодальный промпт, который по изображению документа определяет его тип: «заключение», «рецепт», «анализы», «направление», «план лечения». Если изображение не является документом, промпт должен вернуть `"unknown"` и пояснение.

**Проверяемый результат:**  
- Тип определён корректно  
- Для недокументов — `"unknown"`  
- При низкой уверенности — дополнительный комментарий  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
Изображение скана заключения врача.

**Эталон / подход к проверке:**  
Сравнение с эталонной меткой. Accuracy ≥ 85% на тестовой выборке из 20 изображений.

**Варианты параметризации:**  
- Добавить изображения с текстом, но не документы  
- Изменить разрешение изображений  
- Добавить несколько документов на одном фото

---

## Задача №3. Извлечение структурированных данных из таблицы на изображении

**Условие:**  
Разработайте мультимодальный промпт для извлечения данных из таблицы (например, результатов анализов) и преобразования их в JSON-массив объектов. Таблица может содержать заголовки и числовые значения.

**Проверяемый результат:**  
- Таблица корректно распознана  
- Заголовки извлечены  
- Числовые значения преобразованы в числа  
- JSON-структура соответствует таблице  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
Изображение таблицы с результатами анализов крови (показатели, значения, референсные интервалы).

**Эталон / подход к проверке:**  
Сравнение извлечённого JSON с эталоном. Проверяется точность каждой ячейки.

**Варианты параметризации:**  
- Добавить объединённые ячейки  
- Изменить ориентацию таблицы (вертикальная)  
- Добавить рукописные пометки

---

## Задача №4. Оценка уверенности при частичном распознавании

**Условие:**  
Создайте промпт, который извлекает текст из изображения, но при этом для каждого извлечённого слова/фразы указывает уровень уверенности. Если уверенность < 0.5, слово помечается как `"[неразборчиво]"`.

**Проверяемый результат:**  
- Слова с низкой уверенностью помечены  
- Общая оценка уверенности вычислена  
- Текст максимально сохранён  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
Изображение с частично залитым текстом.

**Эталон / подход к проверке:**  
Проверяется, что неразборчивые участки отмечены, а остальной текст распознан верно.

**Варианты параметризации:**  
- Изменить степень повреждения  
- Добавить разные шрифты  
- Добавить рукописный текст

---

## Задача №5. Улучшение качества изображения через промпт

Разработайте мультимодальный промпт, который анализирует изображение и выдаёт рекомендации по его улучшению (выпрямление, контраст, устранение теней), а также оценивает читаемость после обработки. Выход — JSON с параметрами коррекции.

**Проверяемый результат:**  
- Рекомендации соответствуют дефектам изображения  
- Параметры коррекции реалистичны  
- Оценка читаемости согласуется с рекомендациями  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
Изображение с неравномерным освещением.

- Добавить разные типы дефектов (блики, тени, размытие)
