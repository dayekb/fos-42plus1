# Банк задач «JSON-извлечение»

**Аннотация:** Задачи на извлечение сущностей в строгом JSON-формате из текстов медицинских документов, юридических актов, финансовой отчётности. Акцент на точность извлечения, обработку пропущенных данных и валидацию JSON-схемы.

---

## Задача №1. Извлечение из медицинского заключения

**Условие:**  
Разработайте промпт для извлечения из медицинского заключения сущностей: `patient_name`, `diagnosis`, `doctor`, `clinic`, `date`. Верните результат в JSON с обязательными полями. Если какое-то поле отсутствует, укажите `null`.

**Проверяемый результат:**  
- JSON валиден синтаксически  
- Все обязательные поля присутствуют  
- Значения семантически корректны  
- Отсутствуют галлюцинации  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
```
«Заключение терапевта №45 от 15.05.2026. Пациент: Петров Иван Сергеевич. Диагноз: гипертоническая болезнь II стадии. Лечащий врач: Смирнова Е.А., ГКБ №7. Рекомендовано: контроль давления, диета №10.»
```

**Эталон / подход к проверке:**  
Сравнение с ground truth:  
```json
{
  "patient_name": "Петров Иван Сергеевич",
  "diagnosis": "гипертоническая болезнь II стадии",
  "doctor": "Смирнова Е.А.",
  "clinic": "ГКБ №7",
  "date": "2026-05-15"
}
```
Проверяется точность извлечения каждого поля. Допустимое отклонение — только в формате даты (может быть "15.05.2026").

**Варианты параметризации:**  
- Изменить структуру документа (добавить историю болезни)  
- Усложнить текст (наличие рукописных пометок, аббревиатур)  
- Добавить поле `recommendations`

## Задача №2. Извлечение из финансовой отчётности

**Условие:**  
Разработайте промпт для извлечения из текста финансового отчёта сущностей: `company_name`, `revenue`, `net_profit`, `period`, `currency`. JSON-схема задана. Обработайте случай, когда какое-то поле отсутствует.

**Проверяемый результат:**  
- Соответствие типам данных (числа для revenue и net_profit)  
- Корректное определение валюты и периода  
- Отсутствие выдуманных цифр  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
«Выручка компании ООО "Ромашка" за 2025 год составила 120 млн рублей. Чистая прибыль — 15 млн рублей.»

**Эталон / подход к проверке:**  
```json
{
  "company_name": "ООО Ромашка",
  "revenue": 120000000,
  "net_profit": 15000000,
  "period": "2025",
  "currency": "RUB"
}
```
Оценивается точность чисел и единиц измерения.

**Варианты параметризации:**  
- Изменить валюту (USD, EUR)  
- Добавить несколько периодов  
- Усложнить текст (включить примечания)

## Задача №3. Извлечение из юридического акта

**Условие:**  
Напишите промпт для извлечения из договора сущностей: `parties` (массив), `subject`, `amount`, `sign_date`. Вывод должен быть в JSON с обязательными полями.

**Проверяемый результат:**  
- Корректно выделены стороны договора  
- Сумма извлечена как число  
- Дата приведена к единому формату  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
«Договор поставки № 12/23 между ООО "Альфа" и ЗАО "Бета" на сумму 450 000 рублей. Подписан 01.02.2026. Предмет поставки — медицинское оборудование.»

**Эталон / подход к проверке:**  
```json
{
  "parties": ["ООО Альфа", "ЗАО Бета"],
  "subject": "медицинское оборудование",
  "amount": 450000,
  "sign_date": "2026-02-01"
}
```
Проверяется правильность извлечения суммы и даты.

**Варианты параметризации:**  
- Добавить третью сторону  
- Усложнить валюту (с указанием НДС)  
- Включить ссылки на дополнительные документы

## Задача №4. Обработка частично отсутствующих данных

**Условие:**  
Разработайте промпт, который извлекает сущности из текста, но если какое-то поле невозможно определить, он должен указать `null` и добавить поле `missing_fields` с пояснением. JSON-схема включает: `patient_name`, `birth_date`, `diagnosis`, `allergies`.

**Проверяемый результат:**  
- Все поля присутствуют в выводе  
- Отсутствующие поля явно отмечены  
- Поле `missing_fields` содержит перечень пропущенных сущностей  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
«Пациент: Сидорова А.И. Диагноз: сахарный диабет 2 типа. Аллергий нет.»

**Эталон / подход к проверке:**  
```json
{
  "patient_name": "Сидорова А.И.",
  "birth_date": null,
  "diagnosis": "сахарный диабет 2 типа",
  "allergies": "нет",
  "missing_fields": ["birth_date"]
}
```

**Варианты параметризации:**  
- Убрать несколько полей  
- Добавить противоречивые данные  
- Указать неправильный формат даты

**Сложность:** ★★★ (продвинутая)

Текст с сущностями (см. задачу 1) и схема с типами.
