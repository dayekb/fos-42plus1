# Банк задач «Базовые паттерны»

**Аннотация:** Задачи на отработку zero-shot, few-shot, Chain-of-Thought и self-consistency промптов в различных доменах (медицина, финансы, образование, юридические тексты). Предназначен для формирования навыков выбора и применения базовых техник промпт-инжиниринга.

---

## Задача №1. Zero-shot классификация

**Условие:**  
Разработайте zero-shot промпт для классификации текстов на три категории: «Новость», «Мнение», «Реклама». Промпт должен содержать роль модели, инструкцию и ожидаемый формат вывода (JSON с полями `category` и `confidence`).

**Проверяемый результат:**  
- Задана корректная роль модели  
- Инструкция описывает задачу без примеров (zero-shot)  
- Формат вывода соответствует JSON-схеме  
- Confidence корректно отражает уверенность модели  

**Сложность:** ★ (начинающий)  

**Входные данные:**  
```json
{
  "text": "Вчера в Москве открылась новая клиника инновационной медицины. Ожидается, что она будет принимать до 500 пациентов в день."
}
```

**Эталон / подход к проверке:**  
Сравнение с эталонной классификацией (ground truth). Проверяется `category` («Новость»). Confidence ≥ 0.7 считается приемлемым. Допустимый порог accuracy — ≥ 85% на 10 тестовых примерах.

**Варианты параметризации:**  
- Изменить домен (финансы, образование, спорт)  
- Добавить четвёртую категорию («Научная статья»)  
- Убрать поле `confidence` и добавить поле `reasoning` (краткое обоснование)

## Задача №2. Few-shot с тремя примерами

**Условие:**  
Напишите few-shot промпт для извлечения из текста названия лекарства, дозировки и способа применения. Предоставьте три примера для разных медицинских документов. Используйте структурированный JSON-вывод.

**Проверяемый результат:**  
- Предоставлены 3 релевантных примера  
- Инструкция описывает задачу и формат вывода  
- Извлечены все три сущности  
- Значения корректны семантически  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
```
«Пациенту назначен Амоксициллин 500 мг по 1 таблетке 3 раза в день в течение 7 дней.»
```

**Эталон / подход к проверке:**  
Сравнение с ground truth:  
```json
{
  "medication": "Амоксициллин",
  "dosage": "500 мг",
  "frequency": "по 1 таблетке 3 раза в день"
}
```
Оценивается точность (precision) и полнота (recall) по каждому полю. F1 ≥ 0.9 — отлично.

**Варианты параметризации:**  
- Изменить количество примеров (k=1, k=5)  
- Добавить сущность «противопоказания»  
- Изменить домен (ветеринария, стоматология)

## Задача №3. Chain-of-Thought (CoT) для логической задачи

**Условие:**  
Спроектируйте CoT-промпт для решения логической задачи: «Врач назначил пациенту курс лечения: 5 дней по 2 таблетки, затем 3 дня по 1 таблетке, затем перерыв 2 дня. Сколько всего таблеток примет пациент за весь курс?» Промпт должен содержать пошаговое рассуждение.

**Проверяемый результат:**  
- Промпт содержит инструкцию «подумай шаг за шагом»  
- Модель демонстрирует процесс рассуждения  
- Получен корректный числовой ответ  

**Сложность:** ★★ (средняя)  

**Входные данные:**  
Текстовое описание задачи (см. условие).  

**Эталон / подход к проверке:**  
Правильный ответ: 13 таблеток (5×2 + 3×1). Оценивается наличие пошагового рассуждения и корректность итогового ответа. Ответ без рассуждения считается неполным.

**Варианты параметризации:**  
- Усложнить условие (добавить скидку, замену препарата)  
- Сменить домен (финансовый кейс, логистика)  
- Добавить требование «проверь своё решение»

## Задача №4. Self-Consistency для повышения точности

**Условие:**  
Разработайте промпт с использованием техники самосогласованности (self-consistency) для задачи классификации отзывов на тональность (позитивная/негативная). Промпт должен генерировать 5 цепочек рассуждений (CoT) и выбирать финальный ответ большинством голосов.

**Проверяемый результат:**  
- Промпт запрашивает несколько цепочек рассуждений  
- Финальный ответ выбирается голосованием  
- Точность выше, чем при одиночном CoT  

**Сложность:** ★★★ (продвинутая)  

**Входные данные:**  
Текст отзыва: «Врач очень внимательный, но долго ждал приёма 30 минут. В целом всё хорошо.»

**Эталон / подход к проверке:**  
Ожидаемый ответ: «позитивная» (преобладает позитив). Оценивается, что модель сгенерировала 5 различных рассуждений, и финальный ответ совпадает с большинством.

**Варианты параметризации:**  
- Изменить число цепочек (3, 7)  
- Добавить ещё одну категорию (нейтральная)  
- Усложнить текст (противоречивые высказывания)
