## Вопросы

### 1. (Б) Что характерно для мультимодальных промптов? (Выберите все верные)

A. Они работают только с текстом  
B. Они могут обрабатывать изображения, аудио и видео  
C. Они требуют специальных моделей (например, GPT-4V)  
D. Они всегда используют chain-of-thought  

✅ **Правильные ответы:** B, C

---

### 2. (Б) Как реализуется условная логика в цепочках промптов?

A. Через использование разных моделей для каждой ветки  
B. С помощью if-then-else конструкций в промпте, которые направляют выполнение по разным путям  
C. Путём случайного выбора одного из нескольких промптов  
D. Только через feature-флаги в коде  

✅ **Правильный ответ:** B

---

### 3. (С) Что такое цепочка промптов (prompt chaining)?

A. Последовательное выполнение нескольких промптов, где результат каждого этапа передаётся на следующий  
B. Параллельный запуск нескольких промптов  
C. Использование одного промпта для решения всех задач  
D. Циклическое выполнение одного промпта  

✅ **Правильный ответ:** A

---

### 4. (С) Какие компоненты входят в типичную цепочку промптов для обработки изображения медицинского документа?

A. Классификация → Извлечение текста → Извлечение сущностей → Валидация  
B. Извлечение текста → Классификация → Валидация  
C. Валидация → Классификация → Извлечение текста  
D. Только извлечение текста и классификация  

✅ **Правильный ответ:** A

---

### 5. (С) Что такое feature flags в контексте пайплайнов промптов?

A. Конфигурационные флаги, позволяющие динамически включать/выключать функции без переразвёртывания  
B. Флаги, указывающие на наличие ошибок в промптах  
C. Метки для версионирования промптов  
D. Параметры API для настройки модели  

✅ **Правильный ответ:** A

---

### 6. (П) Как правильно обрабатывать ошибки в цепочке промптов?

A. Прерывать выполнение при первой ошибке  
B. Игнорировать ошибки и продолжать выполнение  
C. Реализовать fallback-сценарии и graceful degradation  
D. Перезапускать цепочку с начала  

✅ **Правильный ответ:** C

---

### 7. (П) Какое преимущество даёт использование цепочек промптов (prompt chaining) по сравнению с одним сложным промптом?

A. Упрощается отладка и тестирование каждого этапа  
B. Снижается общее количество токенов  
C. Увеличивается скорость выполнения  
D. Упрощается написание промпта  

✅ **Правильный ответ:** A
