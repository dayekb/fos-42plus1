## Вопросы

### 1. (Б) Установите соответствие между этапом CI/CD и действием с промптами:

| Этап CI/CD | Действие |
|------------|----------|
| 1. Pull Request | A. Запуск регрессионных тестов промптов |
| 2. Сборка | B. Инкрементальное тестирование только изменённых промптов |
| 3. Деплой в staging | C. Проверка качества и A/B-тестирование |
| 4. Продакшен | D. Мониторинг и сбор метрик производительности |

✅ **Правильный ответ:** 1-B, 2-A, 3-C, 4-D

---

### 2. (Б) Что такое инкрементальное тестирование промптов?

A. Запуск всех тестов при каждом изменении  
B. Запуск только тестов, связанных с изменёнными промптами  
C. Тестирование только в production окружении  
D. Ручное тестирование каждого промпта  

✅ **Правильный ответ:** B

---

### 3. (С) Какие метрики используются для оценки качества промптов? (Выберите все верные)

A. Точность (accuracy)  
B. Полнота (recall)  
C. F1-score  
D. Количество токенов в промпте  
E. Latency (время отклика)  

✅ **Правильные ответы:** A, B, C, E

---

### 4. (С) Что такое canary-развёртывание в контексте CI/CD для промптов?

A. Развёртывание новой версии сразу на всех пользователей  
B. Развёртывание новой версии на небольшой подмножество пользователей для проверки  
C. Полный откат к предыдущей версии  
D. Развёртывание только в staging окружении  

✅ **Правильный ответ:** B

---

### 5. (С) Какое условие должно выполняться для автоматического продвижения новой версии промпта в production?

A. Новая версия должна проходить все регрессионные тесты  
B. Новая версия должна быть одобрена всеми разработчиками  
C. Новая версия должна иметь более высокий quality score, чем текущая  
D. Верны A и C  

✅ **Правильный ответ:** D

---

### 6. (П) Какие этапы включает жизненный цикл промпта в CI/CD пайплайне? (Выберите все верные)

A. Разработка и тестирование промпта  
B. Регистрация в Prompt Registry с версией  
C. Развёртывание в staging с A/B-тестированием  
D. Продвижение в production с мониторингом  
E. Анализ метрик и итерация  

✅ **Правильные ответы:** A, B, C, D, E

---

### 7. (П) Какой подход к тестированию промптов позволяет минимизировать время выполнения CI/CD пайплайна при большом количестве промптов?

A. Запуск всех тестов при каждом коммите  
B. Инкрементальное тестирование только изменённых промптов  
C. Параллельный запуск всех тестов  
D. Отказ от автоматического тестирования  

✅ **Правильный ответ:** B
