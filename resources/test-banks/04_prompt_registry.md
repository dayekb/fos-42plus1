## Вопросы

### 1. (Б) Что такое Prompt Registry (реестр промптов)?

A. База данных для хранения истории чатов с LLM  
B. Централизованное хранилище для управления версиями и жизненным циклом промптов  
C. Инструмент для визуализации архитектуры нейронных сетей  
D. Сервис для мониторинга использования API  

✅ **Правильный ответ:** B

---

### 2. (Б) Какой подход рекомендуется для организации промптов по окружениям?

A. Хранить все версии в одной папке без маркировки  
B. Использовать release labels для указания стадии (prod/staging/beta)  
C. Создавать отдельный репозиторий для каждого окружения  
D. Использовать разные модели для разных окружений  

✅ **Правильный ответ:** B

---

### 3. (Б) Какие практики относятся к версионированию промптов? (Выберите все верные)

A. Использование семантического версионирования (SemVer) для промптов  
B. Хранение только финальной версии промпта  
C. Отслеживание изменений через Git-подобные диффы  
D. Возможность отката к любой предыдущей версии  
E. Использование release labels (prod, staging, beta)  

✅ **Правильные ответы:** A, C, D, E

---

### 4. (С) Что означает изменение MAJOR версии (например, с 1.2.0 на 2.0.0) в семантическом версионировании промпта?

A. Исправление ошибок и улучшение качества  
B. Добавление новой функциональности (обратно совместимо)  
C. Несовместимые изменения, ломающие ожидаемое поведение  
D. Обновление документации  

✅ **Правильный ответ:** C

---

### 5. (С) Какие поля должны содержаться в метаданных промпта? (Выберите все верные)

A. id и version  
B. description и model  
C. parameters (temperature, max_tokens)  
D. changelog  
E. количество использований промпта  

✅ **Правильные ответы:** A, B, C, D

---

### 6. (С) Почему промпты рекомендуется хранить отдельно от кода приложения?

A. Это ускоряет компиляцию  
B. Это позволяет не-разработчикам редактировать промпты через UI и упрощает версионирование  
C. Это снижает стоимость API-запросов  
D. Это улучшает производительность модели  

✅ **Правильный ответ:** B

---

### 7. (П) Какой подход к хранению версий промптов обеспечивает наилучшую воспроизводимость?

A. Хранение только latest версии  
B. Immutable version history – каждая версия неизменна, с возможностью отката к любой предыдущей  
C. Перезапись старой версии при создании новой  
D. Хранение всех версий в одном файле с комментариями  

✅ **Правильный ответ:** B
