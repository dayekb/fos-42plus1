# Тестовый банк №1: Архитектура промпта и параметры API

**Аннотация:** Тестовые вопросы по структуре промпта, системному и пользовательскому промптам, параметрам генерации (temperature, top-p, top-k, max_tokens), их влиянию на вывод модели и практике выбора под задачу.

---

## Параметры банка

| Параметр | Описание |
|---|---|
| **Темы** | Структура промпта (системный, пользовательский, контекст, инструкция, примеры); параметры API (temperature, top-p, top-k, max_tokens); влияние параметров на вывод; выбор параметров под задачу. |
| **Количество заданий** | 7 |
| **Уровни сложности** | Базовый (Б) – 5 вопросов; Средний (С) – 2 вопроса |
| **Правила выборки** | Случайная выборка 5 вопросов из 7; обязательное включение 1 вопроса по параметрам API и 1 вопроса по структуре промпта. |
| **Ключи** | Правильные ответы выделены ✅ в тексте банка. Для автоматической проверки используется файл `answers/01_architecture_answers.json`. |
| **Порядок обновления** | Ежегодно, при изменении лекционного материала по архитектуре промптов и параметрам API. |

## Вопросы

### 1. (Б) Какой параметр API управляет степенью случайности (креативности) ответов модели?

A. top-p  
B. temperature  
C. max_tokens  
D. frequency_penalty  

✅ **Правильный ответ:** B

---

### 2. (Б) Установите соответствие между параметром генерации и его описанием:

| Параметр | Описание |
|----------|----------|
| 1. temperature | A. Ограничивает выбор токенов первыми K наиболее вероятными |
| 2. top-p | B. Контролирует случайность; 0 – детерминированный вывод, выше – более креативный |
| 3. top-k | C. Ограничивает выбор токенов кумулятивной вероятностью p |
| 4. max_tokens | D. Ограничивает максимальную длину ответа |

✅ **Правильный ответ:** 1-B, 2-C, 3-A, 4-D

---

### 3. (Б) Какой параметр API ограничивает максимальное количество токенов в ответе модели?

A. temperature  
B. top_p  
C. max_tokens  
D. presence_penalty  

✅ **Правильный ответ:** C

---

### 4. (Б) Какие элементы входят в архитектуру качественного промпта? (Выберите все верные)

A. Роль (system role)  
B. Инструкция / задача  
C. Количество параметров модели  
D. Контекст и ограничения  
E. Ожидаемый формат вывода  

✅ **Правильные ответы:** A, B, D, E

---

### 5. (Б) Какое значение temperature рекомендуется для фактологических задач (например, извлечение сущностей)?

A. 0.0–0.3  
B. 0.5–0.7  
C. 0.7–1.0  
D. 1.0–1.5  

✅ **Правильный ответ:** A

---

### 6. (С) Что происходит при увеличении значения top-p (nucleus sampling)?

A. Модель становится более детерминированной  
B. Увеличивается разнообразие возможных ответов  
C. Уменьшается длина ответа  
D. Модель начинает игнорировать системный промпт  

✅ **Правильный ответ:** B

---

### 7. (С) Расположите этапы создания промпта в правильной последовательности:

1. Определение роли модели  
2. Формулировка задачи  
3. Указание формата вывода  
4. Добавление контекстной информации  
5. (Опционально) Добавление примеров (few-shot)  

✅ **Правильный ответ:** 1 → 2 → 4 → 5 → 3 (или 1 → 2 → 4 → 3 → 5 – допустимый вариант)
