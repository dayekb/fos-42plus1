## 🔗 Связь с другими компонентами УМК

| Компонент | Взаимодействие с учебниками |
|---|---|
| **Problem‑Banks** | Теоретические основы из учебников необходимы для решения практических задач (например, понимание трансформеров — для CoT, знание оптимизации — для подбора параметров API). |
| **Test‑Banks** | Вопросы тестов опираются на ключевые концепции, изложенные в учебниках (архитектура LLM, параметры генерации, механизмы внимания). |
| **Software** | Учебники с примерами кода (Dive into Deep Learning) синхронизированы с инструментарием (PyTorch, LangChain), что облегчает интеграцию теории в практическую разработку. |

## 📌 Рекомендации по использованию

- **Для студентов:**  
  Изучайте главы учебников параллельно с лекциями. Особое внимание уделите разделам о трансформерах (все учебники), механизмам внимания и методам генерации (Zhang et al., Николенко и др.). Это поможет обоснованно выбирать техники промптинга и параметры API.

- **Для преподавателей:**  
  Рекомендуйте конкретные главы перед выполнением соответствующих КИМов. Например, перед КИМ № 1.10 (мультимодальность) — главы о компьютерном зрении и комбинировании модальностей.
