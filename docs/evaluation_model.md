# Сводная система оценивания курса «Инженерия промптов и LLM-систем»

**Максимальный итоговый балл за курс:** 100 баллов.

Итоговая оценка формируется как сумма баллов за все модули текущей и промежуточной аттестации, а также итоговый экзамен.

Каждый модуль состоит из двух частей:
- **Текущий и рубежный контроль** — до 10 баллов
- **Проект** — до 10 баллов

## 2. Дополнительные требования и правила допуска

Для обеспечения качественного освоения материала и успешной итоговой аттестации устанавливаются следующие правила:

1. **Порог зачёта по модулю**:  
   Каждый модуль считается **зачтённым**, если за него набрано **строго больше 9 баллов** (т.е. ≥ 9 из 20 возможных). Это обязательное условие для формирования базовых компетенций и допуска к итоговой аттестации.
2. **Допуск к экзамену**:  
   Студент допускается к итоговому экзамену только при условии успешного зачёта всех четырёх модулей (каждый > 9 баллов) и выполнения всех обязательных лабораторных и проектных работ курса.
3. **Минимальный порог по экзамену**:  
   Для получения положительной итоговой оценки за курс необходимо набрать на экзамене не менее минимального проходного балла, установленного рабочей программой (рекомендуется ≥ 10 баллов из 20).
4. **Общий минимальный порог**:  
   Для получения итоговой оценки «Удовлетворительно» сумма баллов за весь курс (модули + экзамен) должна составлять **не менее 40 баллов из 100**.
5. **Округление**:  
   Итоговый балл за курс округляется по правилам математики до целого числа перед переводом в традиционную оценку.
6. **Пересдачи**:  
   Порядок пересдачи задолженностей регламентируется действующими правилами образовательной организации. Пересдача проектных работ может сопровождаться снижением максимально возможного балла за соответствующее задание (например, с применением коэффициента 0.8).

## 4. Формула итогового расчёта

**Итоговый балл** =  
`(ТК_М1 + П_М1) + (ТК_М2 + П_М2) + (ТК_М3 + П_М3) + (ТК_М4 + П_М4) + Экзамен`

Где:
- `ТК_Мi` — балл за текущий/рубежный контроль i-го модуля (макс. 10)
- `П_Мi` — балл за проект i-го модуля (макс. 10)
- `Экзамен` — балл за итоговый экзамен (макс. 20)

*Условие допуска к экзамену: `(ТК_Мi + П_Мi) > 9` для всех i = 1, 2, 3, 4.*
