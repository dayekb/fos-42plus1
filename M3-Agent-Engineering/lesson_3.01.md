## 03. Теоретическое введение

### 3.1. Паттерн ReAct (Reasoning + Acting)

**ReAct** — паттерн, в котором агент чередует этапы рассуждения (Reasoning) и действий (Acting). На каждом шаге агент:
1. **Think** — анализирует текущее состояние и формулирует план
2. **Act** — выполняет действие (вызов инструмента)
3. **Observe** — получает результат и обновляет контекст

**Применение:** задачи с неопределённостью, требующие адаптивного поведения.

### 3.2. Паттерн Plan&Solve

**Plan&Solve** — агент сначала строит полный план решения задачи, а затем последовательно его выполняет. Этапы:
1. **Plan** — декомпозиция задачи на подзадачи
2. **Execute** — выполнение каждой подзадачи
3. **Evaluate** — проверка результата

**Применение:** сложные задачи с чёткой структурой, где можно заранее спланировать шаги.

### 3.3. Паттерн Tool-use (Function Calling)

**Tool-use** — агент использует LLM для выбора и вызова внешних инструментов (функций). LLM генерирует структурированный JSON с параметрами вызова.

**Применение:** задачи с фиксированным набором операций (API-вызовы, запросы к БД).

### 3.4. Сравнение паттернов

| Критерий | ReAct | Plan&Solve | Tool-use |
|----------|-------|------------|----------|
| Гибкость | Высокая | Средняя | Низкая |
| Скорость | Медленная | Средняя | Быстрая |
| Токены | Много | Много | Мало |
| Применимость | Адаптивные задачи | Структурированные | API-интеграции |
