## Примечания

- Все КИМ модуля 3 входят в **текущий контроль** (40% итоговой оценки дисциплины) и являются обязательными для получения зачёта по модулю.
- Для каждого КИМ предусмотрены **базовый, средний и продвинутый** уровни сложности; продвинутый уровень даёт бонусные баллы.
- Подробные критерии оценивания, рубрики и пороговые значения метрик приведены в соответствующих методических указаниях.

## Рекомендуемые инструменты и фреймворки

- **LangChain / LangGraph** — для реализации агентов с памятью и инструментами
- **CrewAI / AutoGen** — для мультиагентных систем
- **Qdrant / ChromaDB** — для долгосрочной векторной памяти
- **FastAPI** — для REST API агента
- **Docker** — для контейнеризации
